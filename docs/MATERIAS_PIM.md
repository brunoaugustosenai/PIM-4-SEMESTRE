# NAXAPA — Relação entre disciplinas e implementação

| Matéria | Conteúdo utilizado | Onde foi aplicado | Como foi aplicado |
|---|---|---|---|
| Empreendedorismo em TI | Problema, público, proposta de valor, diferenciais | Escopo NAXAPA | Plataforma integrada para estabelecimentos alimentícios, redução de fragmentação entre gestão, pedidos e produção |
| Relações Étnico-Raciais e Afrodescendência | Inclusão, não discriminação, acessibilidade e cidadania | Gestão Web/Mobile | Interface responsiva, contraste/temas, navegação consistente e base para acessibilidade sem discriminação por perfil pessoal |
| Desenvolvimento Web com .NET | ASP.NET Core, MVC, REST, segurança | Naxapa.Web | Gestão Web + API `/api/v1`, autenticação, autorização e OpenAPI |
| Desenvolvimento Mobile | Flutter, navegação, autenticação, sincronização | Naxapa.Mobile | Dart/Flutter, API REST, cache SQLite, catálogo, adicionais, carrinho e pedidos |
| Programação Aplicada em .NET | OOP, serviços, modularização, responsabilidades | Web, PDV e Print Agent | Controllers, serviços, entidades, clientes API e componentes separados por responsabilidade |
| Programação de Banco de Dados | MER/lógico/físico, constraints, procedures, triggers, índices | NaxapaDB | SQL Server com schemas, PK/FK, CHECK/UNIQUE, procedures transacionais, triggers, views e índices |
| Cloud Computing / DevOps | Configuração por ambiente, build, publicação, automação | scripts e configuração | Variáveis de conexão, Build-All, publicação self-contained dos clientes Windows e estrutura preparada para CI/CD/cloud |
| Gerenciamento Ágil | Incrementos, backlog, validação | Processo do projeto | Desenvolvimento por módulos e relatórios de status/pendências; Kanban/sprints devem ser formalizados na documentação acadêmica final |
